# **Student Management System**

**Project Type:** Academic

This is a **Student Management System** designed to manage administrative tasks for tuition centers in Sri Lanka. Developed as an academic project, it demonstrates skills in **Java programming, database management, CRUD operations, exception handling, and data validations**. The project also showcases experience with frameworks and tools like **FlatLaf for UI and JasperReports for reporting**.

---

## **Features**

- **Admin Login**
  - Secure login for administrators to access the system.

- **Student Management**
  - Register new students
  - Sort and search students
  - Print student lists

- **Teacher Management**
  - Register new teachers
  - Sort and search teachers
  - Print teacher lists

- **Payment Management**
  - Search students enrolled in classes and view payment details
  - Record student payments
  - Print payment bills

- **Subject Registration & Teacher Assignment**
  - Register subjects for students
  - Assign teachers to subjects

- **Class Scheduling**
  - Manage class schedules efficiently

- **New Class Batch Management**
  - Create and manage new batches of classes

- **Student Attendance Marking**
  - Record and track student attendance

- **Logout**
  - Securely log out of the system

---

## **Technologies Used**

- **Programming Language:** Java
- **Database:** MySQL
- **UI Framework:** FlatLaf + Java Swing
- **Reporting Tool:** JasperReports
- **IDE:** NetBeans 17
- **JDK** JDK 17 

---

## **Purpose**

- Efficient database management with Java
- Handling CRUD operations with proper validations

- Generating reports using JasperReports
